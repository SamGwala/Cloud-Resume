SKYGUARD — Cloud Resilience & Incident Response Platform [In Progress]

Independent Cloud / Platform Engineering Project

AWS · Terraform · Docker

Designed and implemented a reusable AWS platform for deploying and operating containerized applications, with automated incident detection, recovery, validation and escalation.

  • Designed reusable Terraform modules for standardized networking, compute, IAM, monitoring and environment infrastructure.
  • Built an event-driven incident response pipeline using CloudWatch, EventBridge and Lambda to detect failures, classify incidents and select bounded remediation actions.
  • Automated infrastructure and application recovery through AWS Systems Manager, including service remediation, instance replacement and controlled escalation.
  • Implemented recovery validation so successful infrastructure commands are not treated as proof that an application has recovered.
  • Established centralized incident history using DynamoDB to record incident state, affected workload, recovery actions, attempts, outcomes and resolution data.
  • Implemented observability using CloudWatch metrics, structured logs, health checks, alarms and Grafana dashboards.
  • Built a GitHub Actions CI/CD pipeline covering Terraform validation, security checks, application testing, Docker image builds, image scanning, deployment and post-deployment validation.
  • Applied least-privilege IAM, SSM-based administration without SSH, restricted network access, secrets management and container/infrastructure security controls.
  • Designed controlled failure scenarios covering application crashes, service failures, resource exhaustion, unhealthy instances, failed remediation, deployment failures and repeated incidents.
  • Defined a reusable workload onboarding model so compatible applications can consume shared platform capabilities through configuration.
